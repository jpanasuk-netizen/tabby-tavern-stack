VRAM is the law. Default is Qwen only. TabbyAPI EXL3 (:5000) and Ollama (:11435) are real, tested, and gated. Two heavy engines on a 12 GB card can block CUDA instead of erroring. Start them when Qwen is down, or when you mean to fight for VRAM.

THE CONNECTION RULE

  • Path is always /v1 — http://qwen:8080/v1 from another container.
  • Host is the service name, not localhost. Localhost inside a container is that container.
  • Model id is Qwen3.5-9B, not the word “qwen.”
  • If auth is on, send the key. Do not “fix” a 401 by changing the host.
