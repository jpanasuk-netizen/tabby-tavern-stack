# dockroot-mcp

Companion to **Tabby Tavern 2.0**. Read-only Docker MCP tools (`ps` / `logs` / `inspect` / `stats` / `networks`).

This Space is documentation. It is not a live docker socket. On the lab box, `~/dockroot` is a local recipe helper and is not required to be running as a container.
