THE PRODUCT

Tabby Tavern 2.0 is this repo’s Docker Compose lab: TabbyAPI (EXL3 / ExLlamaV3), SillyTavern with shipped character cards, Open WebUI on :3000, Ollama remapped to host :11435, SearXNG, and MCPO. Shared bridge ai-network. MIT. No weights. No live API keys.

A brief Taproot rebrand of Tabby compose was reverted. Tabby names, ports, and brand stay Tabby. Do not docker compose up a llama.cpp / Qwen service as a Tabby step — that would bounce a live server that is not this product.

SIX SERVICES

tabbyapi · :5000

EXL3 inference

Image local/tabbyapi:exl3-fixed. Model dir mount, config.yml at /app/config.yml, shm_size: 16g.

sillytavern · :8000

Character UI

Cards bind-mounted at /opt/cards. Basic auth required to listen on 0.0.0.0.

open-webui · :3000

Dual backend UI

Ollama GGUF and TabbyAPI OpenAI-compatible. Distinct from Taproot WebUI on :3001.

ollama · :11435

GGUF backend

Container still listens on 11434. Host publish is 11435 so host Ollama can keep 11434.

searxng · :8080

Private search

html + json formats. JSON is required for MCPO search and Open WebUI RAG.

mcpo · :8001

MCP gateway

FastMCP server.py, tools under /host-master/. Empty mcpServers crashes the proxy.

YAML THAT MADE IT WORK

Public example keys only. Generate your own api_key / admin_key / SillyTavern auth / SearXNG secret.

model:
  model_dir: models
  model_name: Llama-3.1-8B-Instruct-exl3-6.0bpw
  max_seq_len: 8192
  cache_size: 8192
  cache_8bit: true

# Open WebUI
OLLAMA_BASE_URL=http://ollama:11434
OPENAI_API_BASE_URL=http://tabbyapi:5000/v1

# SillyTavern
browserLaunch.enabled: false
basicAuthMode: true

# SearXNG
search.formats: [html, json]
  • Dockerfile.tabby symlinks /usr/local/cuda-12.8/compat/libcuda.so so exllamav3/Triton can link -lcuda on WSL2.
  • NVIDIA Container Toolkit: deb …/noble main is a malformed apt line. Flat amd64 / works.
  • MCPO must call /app/.venv/bin/python3 (that venv has mcp).
  • Character cards under cards/ are first-class — not credentials, not weights.

MCP + CONNECTIVITY

Tabby’s in-tree MCP is MCPO + mcp-servers/server.py: list_tabbyapi_models, tabbyapi_chat, list_ollama_models, ollama_pull_model, ollama_chat, get_stack_status, searxng_search.

Connection rule. Path is always /v1. Inside compose, host is the service name (http://tabbyapi:5000/v1), never localhost. Full skill: local-ai-stack-connectivity. Read-only docker vision: dockroot-mcp (local recipe helper on the live box, not a running container).

COLD START (TABBY ONLY)

git clone https://github.com/jpanasuk-netizen/tabby-tavern-stack.git
cd tabby-tavern-stack
docker build -f Dockerfile.tabby -t local/tabbyapi:exl3-fixed .
cp -n tabby_config/config.example.yml tabby_config/config.yml
# generate keys, download an EXL3 folder into tabby_models/, then:
docker compose up -d
