THE LAB

Tabby Tavern 2.0 is the whole private lab: TabbyAPI EXL3, SillyTavern cards, Open WebUI :3000, Ollama, SearXNG, MCPO, and llama.cpp Qwen3.5-9B at 262k with operator WebUI :3001, Continue, Grok, Hermes, dockroot. MIT. No weights. No live keys.

This GitHub tree ships the EXL3 compose. The llama.cpp compose lives at ~/taproot on the machine. Tabby service names and ports stay Tabby — a rename was reverted. Do not docker compose up the live llama container from this repo; recreating it would bounce qwen38-llama-server.
