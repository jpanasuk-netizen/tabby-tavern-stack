WHY THE YAML WORK MATTERS

Default images do not compose themselves. Public example keys only — never live secrets.

  • EXL3 only · cache_8bit · mount config.yml → /app/config.yml · libcuda.so from cuda-12.8/compat so WSL2 can -lcuda.
  • Open WebUI :3000 dual backend: http://ollama:11434 and http://tabbyapi:5000/v1.
  • Ollama 11435:11434 so host Ollama keeps 11434. In-network name stays ollama:11434.
  • SillyTavern browserLaunch.enabled: false, basicAuthMode: true (ST refuses 0.0.0.0 without auth).
  • SearXNG search.formats: html + json or MCPO + RAG starve.
  • MCPO FastMCP seven tools under /host-master/, python /app/.venv/bin/python3. Empty mcpServers crashes it.
  • NVIDIA toolkit apt noble main line is malformed; flat amd64 / works.
  • Operator WebUI uses host.docker.internal:1234/v1 because llama is published on the host. Continue uses 127.0.0.1 because Continue is on the host.
  • Networks split — tabby-tavern_ai-network removed from the llama side so two GPU engines cannot both allocate.
