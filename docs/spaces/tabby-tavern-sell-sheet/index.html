WHY THE YAML WORK MATTERS

Default images do not compose themselves. These are the pitfalls this lab actually hit — the keys below are from the public example files, never live secrets.

  • EXL3 only. model_name: Llama-3.1-8B-Instruct-exl3-6.0bpw under model_dir: models. EXL2 crashes current TabbyAPI.
  • 12 GB KV. max_seq_len: 8192, cache_size: 8192, cache_8bit: true. ~8 GB used, ~4 GB left.
  • Mount the file TabbyAPI reads. Compose maps ./tabby_config/config.yml → /app/config.yml. Generate api_key / admin_key.
  • WSL2 linker. shm_size: 16g, CUDA device order, flash-attn / KV flags, and a libcuda.so symlink from cuda-12.8/compat so Triton/exllamav3 can -lcuda.
  • Open WebUI dual backend. OLLAMA_BASE_URL=http://ollama:11434 and OPENAI_API_BASE_URL=http://tabbyapi:5000/v1.
  • Ollama host 11435:11434 so host Ollama on 11434 does not collide. In-network name stays ollama:11434.
  • SillyTavern browserLaunch.enabled: false and basicAuthMode: true — ST refuses 0.0.0.0 without auth.
  • SearXNG search.formats must list html and json or MCPO + RAG starve.
  • MCPO FastMCP mcp-servers/server.py, seven tools under /host-master/, python from /app/.venv/bin/python3. Empty mcpServers crashes MCPO.
  • NVIDIA toolkit apt. The noble main line is malformed; the flat amd64 / repo line works.

SAME MACHINE, DIFFERENT STACK

Taproot — not Tabby, not this repo

On LightBringer (WSL2 Ubuntu), a separate compose project named taproot currently holds the GPU: llama.cpp server qwen38-llama-server on :1234 (Qwen3.5-9B, n_ctx 262144) and Taproot Open WebUI on :3001. Networks were split on purpose — Tabby’s ai-network is not shared with Taproot.

VS Code is how the human drives the lab, not a Tabby container: Linux snap 1.134.0 for class work, Windows VS Code + Remote-WSL on the Taproot tree, Continue pointed at http://127.0.0.1:1234/v1. Grok Build and Hermes live on the host. No Qwen3.5-9B tok/s is published here because it was not measured in this tree.

THE /v1 RULE

Connection rule (from the connectivity companion): path is always /v1. Inside Docker, host is the service name, not localhost. Tabby Open WebUI → http://tabbyapi:5000/v1. Host Continue → http://127.0.0.1:1234/v1. Do not paste /v1/chat/completions into a base URL.
